# React + Create React App

This project is a minimal React setup created with [Create React App](https://github.com/facebook/create-react-app). It runs on React 19 and uses `react-scripts` for the dev server, the build and the test runner.

## Available scripts

Run these from the project folder:

| Command | What it does |
|---|---|
| `npm start` | Starts the dev server at [http://localhost:3000](http://localhost:3000). The page reloads when you save a file, and lint errors show up in the console. |
| `npm test` | Runs the tests in interactive watch mode (React Testing Library + Jest). |
| `npm run build` | Creates an optimized, minified production bundle in the `build` folder, ready to deploy. |
| `npm run eject` | Copies the build configuration into the project. **This cannot be undone.** |

## Lint configuration

ESLint is already wired up through the `react-app` and `react-app/jest` presets declared in `package.json`, so no extra setup is needed to get lint feedback while you develop.
